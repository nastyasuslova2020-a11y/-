Что такое Microsoft Copilot

Семейство ИИ-ассистентов на базе GPT-4o, встроенных в продукты Microsoft. «Copilot» — «второй пилот», концепция ИИ как помощника рядом с человеком. Варианты: бесплатный веб-ассистент, Copilot for Microsoft 365, Copilot в Windows 11 и GitHub Copilot.

«Мы интегрируем ИИ в каждый продукт, которым пользуется человечество.» — Сатья Наделла

Союз с OpenAI

Microsoft вложила в OpenAI более $13 млрд, получив эксклюзивные права на коммерческое использование моделей. Когда GPT-4 появился в Bing, это впервые за 20 лет изменило поисковые войны.

Copilot в Microsoft 365

В Word пишет и редактирует документы, в Excel строит формулы на естественном языке, в PowerPoint создаёт презентации по описанию, в Outlook суммирует переписку, в Teams расшифровывает встречи.

GitHub Copilot

  • Автодополнение: предсказывает код прямо в VS Code, Visual Studio, JetBrains.
  • Chat: диалоговый ИИ внутри IDE для объяснения и рефакторинга.
  • Workspace: агентный режим — планирование задач по GitHub Issues.
